# Reference apps: the quality bar

Goal: when a judge picks up the phone, the first reaction is "this looks like a big company spent a long time on it." The benchmark is apps built by large, experienced product teams. Study how they solve the same problems we have, then apply the principle in our own visual language. Never copy their logos, illustrations, brand colors or exact screens.

| App | Made by | What to learn for Money Navigation |
| --- | --- | --- |
| Toss | Viva Republica (Korea) | One message and one big number per screen. Plain, friendly money copy. Calm greys, generous spacing, confident type. Results feel instant. |
| Apple Wallet / Apple Pay | Apple | Card stack physics, payment confirmation moment (check + haptic), restraint: almost nothing on screen except what matters. |
| Wise | Wise | Fee transparency: shows exactly what you pay, the real rate, and how much you save versus banks. Our verdict screens should be this clear. |
| Revolut | Revolut | Currency exchange flow, live rate updates, smooth number transitions. |
| Apple Maps / Google Maps | Apple / Google | The navigation metaphor done right: timely alerts before the turn, one instruction at a time, glanceable while moving. Our trap warnings should feel like this. |
| Grab | Grab (SEA) | What travelers in Bangkok already know and trust; clear Thai/English handling, payment method choice. |
| Airbnb | Airbnb | Shared-element transitions between list and detail, skeleton loading, warm and precise microcopy. |
| Apple Weather | Apple | Turning data into a glanceable picture; detailed but never cluttered; motion that explains the data. |
| Google Lens / Apple Live Text | Google / Apple | Camera recognition UX: how detected text is highlighted, how results lift out of the camera view. Our scan screen should feel at least this good. |

## How agents use this file
- Lead: before building a screen, name which reference app solves the same problem best and what principle you take from it.
- researcher: when asked to compare a finished screen, compare against the matching app above (official screenshots, App Store pages, design blogs) and list gaps ranked by impact.
- craft: polish until the screen would not look out of place next to the matching reference app.
- reviewer: FAIL a screen that clearly falls below the reference for its type (camera, verdict, home, settings, onboarding).
